\section{2. Layout Patterns: 分栏与图片}

\begin{frame}[fragile]{2. Layout Patterns}
\begin{columns}[T,onlytextwidth]
  \begin{column}{.48\textwidth}
    左侧内容 用于放置主要说明、定义或步骤。
  \end{column}
  \begin{column}{.48\textwidth}
    右侧内容 用于放置补充说明、对比信息或结论。
  \end{column}
\end{columns}
\end{frame}

\begin{frame}[fragile]{2. Layout Patterns}
\begin{columns}[T,onlytextwidth]
  \begin{column}{.48\textwidth}
    左侧内容 图片分栏适合展示案例、截图或结果对比。普通分栏会保留完整标题行，正文和图片从标题下方开始。
  \end{column}

  \end{column}

\end{frame}

\begin{frame}[fragile]{2. Right Fill Text}
\begin{columns}[T,onlytextwidth]
  \begin{column}{.48\textwidth}
    左栏保留标题和主要说明。加上 \texttt{right-fill} 后，左栏正文仍然会避开标题，但不会浪费整行标题高度。
    
    \begin{itemize}
    \item
      适合双栏文字对比
    \item
      左栏作为背景、问题或约束
    \item
      标题不会挤占右栏顶部
    \end{itemize}
  \end{column}
  \begin{column}{.48\textwidth}
    右栏文字从页面顶部开始排版，可以利用原本标题右侧的空间。
    
    \begin{itemize}
    \item
      适合放方案、结论或对照项
    \item
      比普通双栏多一段可用高度
    \item
      不需要图片也能使用 \texttt{right-fill}
    \end{itemize}
  \end{column}
\end{columns}
\end{frame}

\begin{frame}[fragile]{2. Right Fill}
\texttt{right-fill} 用在图片更重要的页面。右侧图片从页面顶部开始占满右栏，左侧标题和正文都保留在左栏。

\begin{itemize}
\item
  适合标志、产品图、实验场景图
\item
  左侧只放结论或必要说明
\item
  右侧图片不要被强行拉伸
\end{itemize}

\includegraphics[width=\linewidth,height=.50\textheight,keepaspectratio]{\VSPasset{ShanghaiTech_Logo_RGB.png}}
\end{frame}

\section{3. Emphasis Styles: 列表与引用}

\begin{frame}[fragile]{3. Emphasis Styles}
VSP-Beamer 提供多种列表和提示框样式，适合报告展示使用。下面几页分别展示双列列表、单列流程、强调引用和代码块。

\begin{itemize}
\item
  \texttt{cols2\_ol\_sq} / \texttt{cols2\_ol\_ci}：双列有序列表
\item
  \texttt{cols2\_ul\_sq} / \texttt{cols2\_ul\_ci}：双列无序列表
\item
  \texttt{col1\_ol\_sq} / \texttt{col1\_ol\_ci}：单列步骤列表
\item
  \texttt{bq-*}：强调引用提示框
\item
  fenced code block：代码块与命令行示例
\end{itemize}
\end{frame}

\begin{frame}[fragile]{3. Emphasis Styles}
\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}

  明确问题背景
\item

\item
  展示关键公式
\item
  分析边界条件
\item
  对比实验结果
\item

\end{enumerate}
\end{frame}

\begin{frame}[fragile]{3. Emphasis Styles}
\begin{itemize}
\item
  适合并列展示多个要点
\item
  每个条目保持短句
\item
  左右两列自动排布
\item
  用于课堂提示或报告 checklist
\item
  避免单页塞入过长段落
\item

\end{frame}

\section{4. Code Examples: 代码块}

\begin{frame}[fragile]{4. Code Examples}
命令行代码适合展示安装、构建和运行步骤。保持命令短、注释少，避免一页放太多终端输出。

\begin{lstlisting}
sudo apt install make
make build
make test
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{4. Code Examples}
Makefile 或配置类代码适合分块展示：先给最小规则，再解释变量和依赖关系。

\begin{lstlisting}
CXX := g++
CXXFLAGS := -Wall -O2

app: main.o utils.o
    $(CXX) $^ -o $@

%.o: %.cpp
    $(CXX) $(CXXFLAGS) -c $< -o $@
\end{lstlisting}
\end{frame}
